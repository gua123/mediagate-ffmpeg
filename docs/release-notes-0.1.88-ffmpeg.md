# 0.1.88-ffmpeg（versionCode 89）

修「声音也跟着变慢」：音频输出采样率与重采样率不一致。

## 现象

2026-11-03 用户反馈：公网/内网、甚至**本地视频**播放都像慢放，而且**声音也变慢了**（变慢变调）。

## 根因

自研引擎里音频重采样固定按 **48000 Hz** 生成 PCM，但 AAudio 共享模式给的实际采样率可能不是 48000（例如 44100）：

- 设备按 44100 帧/秒消费 48k 的数据 ⇒ 声音慢约 8.8%、音调变低；
- 音频时钟按实际率走，媒体时间却按 48k 生成 ⇒ 音画同步判断被带偏，画面跟着被拖成"慢放"。

## 改动

打开音频设备后先读实际采样率，再按它建重采样器（`swr` 输出率 = 实际率），`nextAudioUs` 的步长也改用实际率；音频时钟本来就用实际率，三者终于一致。另含 0.1.87 的送屏优化（BGRA 直出 + 行 memcpy + fill_n）。

## 验证

装好后播同一个本地视频：

1. 声音是否恢复常速、音调正常；
2. 画面是否还像慢放；
3. 设置 → 诊断与日志的「最近播放指标」：丢帧/音频欠载/音画偏差；「音频 ... Hz」会显示设备实际采样率（44100 还是 48000）。
